# 🛒 E-Commerce Sales Analysis and Customer Behavior Prediction Using Machine Learning

## 📌 Project Overview

This project focuses on analyzing e-commerce sales data and predicting customer purchasing behavior using Machine Learning techniques. The project covers the complete Data Science workflow including:

- Data Cleaning & Preprocessing
- Exploratory Data Analysis (EDA)
- Feature Engineering
- Handling Imbalanced Data
- Machine Learning Model Building
- Model Evaluation & Comparison
- Business Insights Generation

The goal of this project is to extract meaningful insights from e-commerce data and build predictive models that can help businesses improve decision-making and customer targeting.

---

# 📂 Dataset Description

The dataset contains transactional e-commerce sales data including:

- Customer Information
- Product Details
- Revenue & Profit
- Discounts
- Shipping Information
- Order Status
- Customer Segments
- Purchase Dates

### Dataset Size
- Total Records: 10,000
- Total Features: 26+

# ⚙️ Feature Engineering

Several new features were created to improve model performance:

- Profit Per Order
- Weekend vs Weekday Orders
- Shipping Delay Category

---

# ⚖️ Handling Imbalanced Data

The dataset contained class imbalance issues, which were addressed using:

1. SMOTE Oversampling
2. Class Weight Balancing

These techniques improved minority class prediction performance.
